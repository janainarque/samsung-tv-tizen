# Samsung TV Tizen

Projeto para desenvolver uma interface alternativa para a Smart TV Samsung UN65DU8000GXZD, utilizando o sistema Tizen.

## Referência

O projeto open source [Free My TV](https://github.com/simbasjungles/free-my-tv) será utilizado como referência para o desenvolvimento.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Python

## Avaliação de memória e desempenho

Como objetivo adicional, será avaliado o consumo de memória RAM e o desempenho da TV antes e depois da instalação da interface, para comparar os resultados e identificar possíveis impactos no funcionamento do aparelho.
